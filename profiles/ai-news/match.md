# AI frontier profile

Use this profile when an item carries concrete, verifiable progress in artificial intelligence: a model, an API, an open-source tool, a benchmark, or a policy that changes what builders can do.

Typical items include model releases and capability changes, API and SDK updates, pricing and context-length changes, open-source releases and major version bumps, reproducible benchmark results, safety evaluations, and regulation with named obligations.

Do not route funding rounds without a product, executive hires, conference and webinar promotion, "AI will change everything" opinion pieces, or benchmark charts without a baseline here.
