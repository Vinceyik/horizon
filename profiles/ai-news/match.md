# AI frontier profile

Use this profile when an item changes what a builder using AI tools can do: a model, an app, an agent, an editor integration, a pricing or availability change.

Typical items include model releases with a usable product, AI coding tools and agents, API and SDK updates, pricing and free-tier changes, open-source apps with a demo, and policy changes that affect access.

Do not route training-infrastructure work (kernels, compilers, distributed training), paper-only results, funding rounds without a product, executive hires, or conference and webinar promotion here.
